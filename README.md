## 这是干什么的？

**SubFlow Studio** 是一款专为 Windows 打造的 **AI 视频双语字幕全流程桌面工具**。

当你手里有一段**没有字幕的英文 / 日文 / 韩文等外语视频**（或你想给自己的视频配上中英双语字幕），传统做法往往需要在多个软件之间来回折腾：下载视频 → 抽音轨 → 找工具听写 → 复制去网页翻译 → 回剪辑软件逐条对齐时间轴 → 调字体样式 → 渲染导出。

**SubFlow Studio 把这一整套流程全部整合进了一个开箱即用的桌面软件里：**

```text
本地视频 / 粘贴 B站·YouTube·抖音链接 / 已有 .SRT
                     │
                     ▼
   [1] 本地 Whisper + Silero VAD 精准听写（免费离线，支持 GPU 10倍加速）
                     │
                     ▼
   [2] 并发大模型全片语境精翻（自动识别 A/B 说话人 + 语音同音错字审校）
                     │
                     ▼
   [3] 60fps 舞台实时预览 & 触控造型台（所见即所得改字号、颜色、位置）
                     │
                     ▼
   [4] 一键导出双语 .SRT / 高级样式 .ASS / NVENC 显卡硬压 MP4 成片
```

### 适合哪些人使用？
- **自媒体 / UP 主 / 译制组**：快速制作 B 站、抖音、小红书、YouTube 的海外科普、评测、访谈、播客双语视频。
- **外语学习者 / 科研与技术从业者**：看海外公开课、技术大会（WWDC / GTC / TED）、无字幕教程时快速生成精准双语对照字幕。
- **跨境电商与出海团队**：把中文产品视频翻译为 12 国语言并直接压制带字幕成品。
- **剪辑师**：一键生成时间轴精准的双语 `.srt` / `.ass`，无缝导入剪映专业版、Premiere Pro、DaVinci Resolve。

## 核心功能亮点

1. **高精度本地语音识别（`faster-whisper` + Silero VAD）**
   - **原始完整时间轴连续解码**：不暴力切碎音频，配合 Silero VAD 只读静音过滤与发声边界校准，解决常见字幕“提前闪现、话没说完就消失、尾句滞留”问题。
   - **GPU / CPU 自适应**：有 NVIDIA 独显自动开启 **CUDA 12 / cuDNN 9 (FP16)**（提速 8~10 倍）；无独显自动以 **CPU INT8** 流畅运行。
   - **多档模型任选**：支持 `small`（推荐，约 460 MB）、`medium`、`large-v3-turbo`，仅首次下载，之后永久离线运行。

2. **高质量并发大模型精翻（告别“机翻味”和乱翻译）**
   - **全片大纲共享语境**：翻译前先汇总全片对话大纲，结合上下文做 **6 路并发精翻**，并自带通用的语音识别同音错字审校（`src_fix`）与专名实体聚类统一，前后人名/术语一致。
   - **零额外请求的双人说话人区分**：自动判断对话中的说话人 A / B，并可为不同说话人配置不同字幕配色。
   - **36 大垂直行业专业术语库**：覆盖 AI/编程、芯片硬件、医学、金融、游戏引擎（UE5）、摄影光学、法律、汽车工程等 36 个领域，可按需开启或关闭。
   - **断网容错不糊弄**：局部网络波动绝不用原文冒充译文，支持点击 **「补翻失败条目」** 仅补翻漏项，也支持任意单句结合上下文 **「AI 重译」**。
   - **12 国语言互译与 12 套界面语言**：支持简/繁中文、英语、日语、韩语、法语、德语、西班牙语、俄语、葡萄牙语、阿拉伯语、泰语等 12 种语言。

3. **60fps 丝滑预览舞台 & 真正无边框影院全屏**
   - 内置本机 `127.0.0.1` 零拷贝 HTTP Range 流媒体服务与 `requestVideoFrameCallback` 逐帧同步，高清视频拖动和播放流畅不卡顿。
   - 支持 **Windows 11 原生零边框全屏**：按 `F11` 进入应用全屏；**双击视频画面**或点击播放栏全屏按钮进入纯黑无边框影院全屏，按 `Esc` 一键退出。
   - **触控造型台与调色台**：实时拖拽调整字幕位置、字号、行距、双语上下顺序、描边、阴影与毛玻璃底框，内置多套高颜值样式预设（B 站科普 / Netflix / Apple 极简 / 赛博霓虹等），所见即所得同步导出到 `.ass` 与 MP4 成片。

4. **多平台视频导入 & 硬件加速硬压成片**
   - 支持导入本地 MP4 / MKV / MOV 等视频、导入已有 `.srt` 字幕，以及基于 `yt-dlp` 的 1000+ 站点链接解析（内置 B 站扫码登录与代理配置）。
   - 支持调用 FFmpeg **`h264_nvenc`（NVIDIA 硬件编码）** 极速烧录字幕成片，无独显时自动回退至高质量 `libx264` 编码。

## 详细使用说明（保姆级教程）

### 0. 30 秒免配置体验效果

装好软件后，哪怕你还没准备视频、也没填 API Key，也可以立刻看成品效果：
1. 启动 **SubFlow Studio**。
2. 点击左上角绿色的 **「新手引导 / 10秒试跑」** 按钮。
3. 点击 **「⚡ 10秒看成品」**，软件会自动加载一段 10 秒双人英语对话示例：
   - 点击播放，体验 60fps 舞台上的 **双人 A/B 双语卡点字幕**；
   - 切到右侧 **「触控造型台」**，拖动二维磁吸光球或切换预设样式，实时看画面变化；
   - 点击右上角 **「导出成片」**，直接测试导出 `.SRT`、`.ASS` 或硬压 `.MP4`。

### 1. 配置 AI 翻译引擎（只需填一次）

> 本地语音听写完全免费离线；将听写出的外语精翻成地道双语并自动区分说话人，需要连接一个大语言模型（支持极低成本的云端 API，也支持**完全免费的本地 Ollama**）。

1. 点击软件右上角 **「偏好设置」** → 左侧选择 **「算力与翻译引擎」**。
2. 在顶部的服务商快捷按钮中任选一种：
   - **DeepSeek（最推荐）**：前往 [DeepSeek 开放平台](https://platform.deepseek.com) 创建 API Key，性价比极高（10 元约可翻译 500~1000 个常规视频，单个 10 分钟视频仅几分钱）。
   - **其他国内/国际服务商**：同样一键支持 **通义千问（Qwen）**、**Kimi**、**智谱 GLM**、**硅基流动（SiliconFlow）**、**OpenAI** 及任意 OpenAI 兼容接口。
   - **本地 Ollama（完全免费离线）**：点击 **「本地 Ollama（免费）」**，配合本机 Ollama 服务即可零费用离线翻译。
3. 粘贴你的 API Key → 点击 **「保存 Key」** → 点击 **「测试连通」**，看到连接成功提示即可关闭设置页（配置自动永久保存）。

---

### 2. 导入视频或已有字幕

点击顶部居中的 **「灵动岛」** 展开导入控制面板：

- **选择语言**：源语言默认 **`AUTO`（自动检测）**，也可手动指定英语、日语、韩语等 12 国语言；目标语言默认简体中文，可按需切换。
- **方式 A — 导入本地视频**：点击 **「导入本地视频」** 选择电脑上的 `.mp4` / `.mkv` / `.mov` 等文件（或直接把本地视频路径粘贴进输入框）。
- **方式 B — 粘贴在线视频链接**：直接粘贴 B 站、抖音、YouTube 等 1000+ 站点链接（支持直接粘贴带标题的分享口令，软件会自动提取 URL）。
  - *B 站高清下载提示*：若 B 站提示需要登录，软件会自动弹出扫码窗口，用手机 B 站 App 扫一下即可获取高清流下载权限，无需读取浏览器加密 Cookie。
- **方式 C — 导入已有 `.SRT` 字幕**：如果你已经有外语字幕文件，可点击 **「导入 .SRT」**，跳过语音识别直接进入大模型精翻与造型排版。

---

### 3. 自动语音识别与双语精翻

点击 **「提取并翻译」** 后，软件会自动完成全流程：

1. **语音识别（Whisper + Silero VAD）**：
   - **首次使用**时会自动从国内高速镜像站（`hf-mirror.com`）下载一次语音模型（默认推荐 `small`，约 460 MB；对高难度多口音视频可在偏好设置切为 `large-v3-turbo`），下载完成后**永久离线使用**。
   - 顶栏右侧会实时显示当前算力引擎：绿色的 `CUDA FLOAT16` 表示已开启 NVIDIA 显卡加速，`CPU INT8` 表示正在使用 CPU 模式。
2. **并发语境精翻**：
   - 如视频涉及特定专业领域，可在设置或行业术语面板中开启对应的 **36 大行业专业术语库**，防止专有名词翻错。
   - 如果翻译中途遇网络波动导致个别条目失败，软件会明确标红提示，不会拿原文冒充译文；只需点击 **「补翻失败条目」** 即可只重翻失败部分。
   - 需要核对精确时间戳时，还可以一键导出 **CSV / JSON 时间轴核对表**。

---

### 4. 精修字幕与实时样式排版

翻译完成后，画面与右侧面板会实时联动：

- **编辑双语字幕流（右侧栏）**：
  - 点击任意一句字幕，左侧视频立刻跳转到该句画面。
  - 双击或直接编辑文本框可手动修改原文/译文。
  - 对某句译文不满意？点击该句的 **「AI 重译」**，大模型会结合前后文重新润色这一句。
  - 觉得一句太长或太碎？选中后按 **`S`** 键拆分、按 **`M`** 键与下一句合并，改错了按 **`Ctrl + Z`** 撤销。
- **触控造型台 & 调色台（右侧切页）**：
  - 直接点选 **B 站科普 / Netflix / Apple 极简 / 赛博霓虹** 等预设风格一键套用。
  - 拖动二维磁吸光球调节字幕高度与字号，自定义双语上下顺序、A/B 双人独立配色、描边粗细与毛玻璃背景透明度，左侧舞台实时 60fps 预览。
- **全屏预览**：
  - 按 **`F11`** 切换整个工作台全屏；
  - **双击视频画面**（或点击播放器右下角全屏按钮）进入纯黑零边框影院全屏，方便沉浸式检查每一句字幕的观感。

---

### 5. 导出字幕或一键硬压成片

确认无误后，点击右上角 **「导出成片」**，按需选择导出方式：

1. **导出标准双语 `.SRT`**：通用纯文本时间轴字幕，可直接拖入剪映专业版、Premiere Pro、DaVinci Resolve 二次剪辑。
2. **导出高定样式 `.ASS`**：完整保留你在造型台里调好的字体、字号、位置、描边、双人分层颜色与底框样式。
3. **硬件编码加速硬压 `.MP4`**：
   - 自动调用 FFmpeg 将样式字幕永久烧录到视频画面中（有 N 卡自动走 `h264_nvenc` 极速压制，无 N 卡自动回退 `libx264`）。
   - 导出完成后会自动打开输出目录并高亮选中你的成片文件！

## 常见问题解答（FAQ）

### Q1：一定要花钱买 API Key 才能用吗？
不需要强制花钱。你有两种选择：
- **完全免费离线**：在「偏好设置 → 算力与翻译引擎」点选 **「本地 Ollama（免费）」**，本机跑开源翻译模型，零费用。
- **极低成本云端高质翻译**：推荐 **DeepSeek**，充值 10 元就能翻译几百个视频，翻译准确度和流畅度显著高于普通本地小模型。

### Q2：我有 NVIDIA 显卡（如 RTX 3060 / 4060 / 4070），怎么确认已开启 GPU 加速？
打开软件后看顶部栏右侧状态徽章：
- 显示 **`CUDA FLOAT16`** = 已成功开启 10 倍 GPU 加速；
- 如果显示 `CPU INT8` 且你装的是 125 MB 轻量版，请前往 Releases 下载安装 **`SubFlowStudio_GPU_Pack_Setup.exe`**（或直接安装全量版 `SubFlowStudioSetup.exe`），重启软件即可生效。

### Q3：首次识别字幕时下载模型很慢或失败怎么办？
软件默认通过国内高速镜像 `hf-mirror.com` 下载 Whisper 模型（`small` 仅约 460 MB）。如果开启了全局代理导致镜像站绕路，可在「偏好设置」中调整或临时关闭代理后重试；模型只需下载一次，之后永久离线复用。

### Q4：下载 B 站视频为什么建议用软件内扫码登录？
B 站对未登录请求有风控（HTTP 412）且限制画质，而新版 Edge / Chrome 对本地 Cookie 采用了系统级加密保护。使用软件内置的 **「B 站扫码登录」** 不会触碰你的浏览器，扫码一次后登录态保存在本机私有目录，后续可直接拉取高清视频。

### Q5：下载 YouTube 视频连不上怎么办？
在「偏好设置 → 网络与下载」中填入你的本地代理地址（例如 `http://127.0.0.1:7897` 或 `http://127.0.0.1:7890`）保存后即可正常解析下载。

## 开发者：从源码运行与构建

### 环境要求
- Windows 10 / 11 (x64)
- Python 3.12（建议勾选 `Add python.exe to PATH`）
- Microsoft Edge WebView2 Runtime（Windows 11 默认内置）
- 可选：`ffmpeg.exe`（放入 `bin/ffmpeg.exe` 或加入系统 `PATH`，用于音轨提取与硬压成片）
- 可选：[Inno Setup 6](https://jrsoftware.org/isinfo.php)（如需打包 `.exe` 安装向导）

### 克隆并一键初始化 / 构建
```powershell
git clone https://github.com/no1kyousuke/asagiri-kyousuke.git
cd asagiri-kyousuke

# 自动创建隔离虚拟环境 .build_venv、安装依赖并构建便携版 EXE（不污染全局 Python）
.\build_windows.bat
```

### 构建产物说明
运行 `build_windows.bat`（或 `python build_release.py`）会生成：
- `dist\SubFlow Studio\`：全量 GPU 便携版（含 CUDA 12 / cuDNN 9 DLL）
- `dist_cpu\SubFlow Studio\`：轻量 CPU 便携版
- `dist_gpu_pack\`：独立 NVIDIA CUDA 12 GPU 加速扩展包
- `installer\`（本机已安装 Inno Setup 6 时）：自动生成上述 3 个版本的 Windows 安装程序
